# 🌐 CodSoft Web Development Internship

A collection of frontend web development projects completed during my internship with CodSoft. These projects focus on responsive design, dynamic layout building, and core web fundamentals.

## 🚀 Included Projects
1. **Portfolio Page:** A personal portfolio website designed to showcase skills and experience. (`PORTFOLIO/`)
2. **Landing Page:** A responsive, visually appealing landing page template. (`Land page/`)
3. **Calculator:** A fully functional web-based calculator app. (`calculator/`)

## 🛠️ Tech Stack
- **Structure:** HTML5
- **Styling:** CSS3
- **Logic:** Vanilla JavaScript

## ⚙️ How to Run
There is no backend server or build process required. 
1. Clone the repository: `git clone https://github.com/HARSHADBALAJI/codsoft-web-internship.git`
2. Navigate into any of the 3 project directories.
3. Open the `index.html` file directly in your preferred web browser to view the application.
